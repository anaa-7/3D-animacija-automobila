# 3D-animacija-automobila

## Opis projekta

Projekt predstavlja 3D animaciju automobila izrađenu u Blenderu u sklopu kolegija 3D računalna grafika.

Cilj projekta je izrada kratke animacije automobila u noćnom gradskom okruženju. Automobil se tijekom animacije prikazuje iz više različitih perspektiva pomoću animirane kamere.

## Korišteni alati

- Blender
- 3D modeliranje
- Materijali i teksture
- Osvjetljenje
- Animacija pomoću keyframeova
- Animirane kamere
- Renderiranje

## Glavne funkcionalnosti

- 3D scena gradskog okruženja
- Animacija kretanja automobila
- Animacija kamere
- Prikaz automobila iz više različitih kadrova
- Noćno osvjetljenje scene
- Refleksije svjetla na cesti
- Renderiranje završne animacije

## Završna animacija

Završna animacija prikazuje automobil u noćnom gradskom okruženju kroz više različitih perspektiva.

**YouTube:** [Pogledaj animaciju] https://youtu.be/TByoJFQIJxw

## Tehnički podaci

- Rezolucija: 1920 × 1080
- Broj frameova: 249
- Brzina: 30 FPS
- Trajanje: približno 8 sekundi
